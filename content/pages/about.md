## 关于我

坐标杭州的全栈工程师，偏爱纯文本、清晰抽象与克制排版。日常关注全栈系统架构、Web 工程实践、服务端与前端工具链，以及如何让技术写作在屏幕上有接近纸质书刊的阅读体验。

写博客的初衷很简单：把零散的排查记录、推演过程与工程决策沉淀下来，逼迫自己用更准确、不绕弯的语言把问题讲清楚。

## 本站说明（Colophon）

这个站点本身也是我的一次极简工程实践：

- **框架与构建**：基于 Next.js App Router、React 19 与 Tailwind CSS v4 构建，全部内容静态预渲染。
- **配置化页面**：首页、归档、项目、关于乃至未来任意扩展页面，均由 `content/pages/` 中的 Markdown 与 YAML 模板字段驱动。
- **字体与色彩**：正文使用思源宋体（Noto Serif SC），代码与数字元信息搭配 Geist Mono，全站克制保持黑白纸墨浅色视觉。
- **排版增强**：通过 Unified / Remark / Rehype 管线在服务端直接编译 KaTeX 公式与 Shiki 代码高亮，减少客户端负担。
